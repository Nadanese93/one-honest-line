# One Honest Line

Entry for the Make.fun micro bounty "One Honest Line" (slug `u-mfnakmal-one-honest-line-ef68037d`): a program that writes one honest line of text.

The line answers the instruction "write it without using AI" — addressed to the AI itself — with a fish-and-water metaphor: hired a fish, banned water.

Run `python3 main.py` and the entry appears as `entry.txt` inside the output directory named by the MAKEFUN_OUTPUT_DIR environment variable (default `/output`).
